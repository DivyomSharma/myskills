# workflow-reel

Announce "Using workflow-reel to <purpose>". Free-first: real product UI in motion first, stills second, AI video last (see CLAUDE.md visual production pipeline).

## Flow
1. brand-system for the venture, asset-management for existing assets.
2. Brief: audience, one message, length, platform.
3. Script and storyboard: one idea per shot.
4. Composition spec per shot. Each frame must look designed when paused.
5. Motion spec: use product-ui-motion, still-to-motion, motion-kit. Add ai-video-shotlist only if the 10% AI budget is justified.
6. Build with Remotion or code animation; process media with ffmpeg.
7. Finish color, audio, and export in DaVinci Resolve (human step).
8. visual-budget-audit before build and after; motion-safety-qa for web embeds.

## Stop
When the film passes the audit. Do not add effects to cover weak composition.
