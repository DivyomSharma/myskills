# brand-system

Announce "Using brand-system to <purpose>".

## How
1. Identify the venture. If unclear, ask once.
2. Read `brands/<venture>.md` in this skill folder.
3. Apply voice, type, color, and visual language from it. Check asset-management for approved assets.
4. If a field is still TODO, say so and ask the user instead of inventing a value.

## Files
`brands/verity.md`, `brands/plotarmour.md`, `brands/convoke.md`, `brands/candor.md`, `brands/neki.md`

Each file holds: positioning, audience, voice, typography, colors, logo, visual language, do, don't, examples.
