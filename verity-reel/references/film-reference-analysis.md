# Reference analysis

Source: the user's reference playlist (YouTube `PL-R-pmo3HkDTOrKKgJSJYYniarc3OwR43`), 37 SaaS product and explainer films,
mostly by one studio. Six were studied frame by frame, as 20-frame contact sheets across each film:

- Avoma (meeting assistant, product demo)
- Kula (outbound recruiting demo)
- Kula (brand launch)
- SuperOps (collage explainer)
- Aerchain (procurement demo)
- Zoho Creator (3D motion graphics)

These are design education only. We do not copy branding, logos, layouts, animations or scripts.

## What makes the strong ones feel refined

**Composition**
- The product UI is shown huge. In Avoma and Kula the UI fills the frame and bleeds off the right and bottom edges. The
  crop is the composition: the frame shows the part being read, never the whole screenshot.
- Each frame has one subject. Type-only frames carry only type; UI frames carry only UI, or UI plus one anchored callout.
- Asymmetry is the default. Centring is saved for single-object frames (logo, one line).

**Typography**
- Statements are short, usually 2 to 7 words, on 1 or 2 lines, set large on an empty field.
- The best films say a concept once and let the UI prove it. The weaker ones narrate every feature in on-screen copy.
- End cards are a mark plus one line plus a very small URL, centred, with lots of space.
- Callouts (Aerchain) are attached to the UI element they explain, not floating in empty space. That idea is worth keeping;
  their black-pill, gradient-text style is not.

**Pacing**
- About one idea every 3 to 5 seconds. Text holds still long enough to read twice, then leaves.
- Type frames and UI frames alternate, so the eye is never asked to read both at once.

**Camera**
- Slow push-ins on UI towards the region that matters (Avoma moves from the full app to the notes column).
- Perspective tilt and depth of field on artefacts (Kula's opening articles, read at an angle with focus falloff) make flat
  things feel physical.
- Lateral tracking across UI rows keeps a continuous feel instead of cuts.

**Transitions**
- The strongest moves are shape-continuous: a ring becomes a tunnel becomes a frame (SuperOps), a tile wall resolves into
  one tile (Zoho). One object carries the eye across the cut.

**Material and lighting**
- Good: real UI on a quiet background, soft shadow, the product lit evenly.
- Bad, and banned for Verity: neon gradient blobs, glowing orbs, rainbow rings, particle bursts, gradient text, saturated
  multi-hue backgrounds. They date a film instantly and fight the UI.

**UI integration**
- UI is the hero and runs at reading scale. It is not shrunk into a laptop mockup or a floating card collage.
- The same surface persists and changes state, so the viewer learns one product, not ten screenshots.

**Negative space**
- Empty space is used to isolate a single statement or a logo. It is never filler beside a small object.

**Visual hierarchy**
- Statement or UI focal element first, one supporting element second, everything else dimmed, cropped or gone.

## Translated into Verity rules

| Observation | Verity rule (see SKILL.md) |
|---|---|
| UI bleeds off the frame at reading scale | Push-in to 1.25-1.4x; crop the trailing edge |
| One subject per frame | One focal point; second element at most 40% weight |
| Short statements, said once | At most 3 lines of about 22 characters; no repeated concepts |
| Callouts attached to the element | Text anchored to a named edge, baseline or cap line |
| Shape-continuous transitions | Transform, don't cut; one handoff object per film |
| Neon, orbs, rings, particles | Banned |
| Centred end card, small URL | Centred brand lockup is the only centred multi-element frame |
