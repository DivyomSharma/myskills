# research

Announce "Using research to <purpose>".

## Flow
1. Restate the question in one sentence and name the decision it informs.
2. Pick sources by type: primary (docs, filings, the product itself) before secondary (articles, forums).
3. Collect evidence with a link or file path per claim.
4. Cross-check any claim that drives the decision against a second source.
5. Synthesize: findings, confidence, gaps, then a recommendation.

## Output
Short answer first. Then evidence table (claim, source, confidence). Mark anything unverified as unverified. Say when the search came back thin.

## Notes
Indian-market questions: prefer local sources and state the date of each figure.
